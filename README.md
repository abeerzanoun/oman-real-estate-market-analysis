# Oman Real Estate Market Analysis

## Project Overview
This project analyzes the real estate market in the Sultanate of Oman using verified data, Python, Excel, and Power BI.

## Objectives
- Analyze real estate market trends over time.
- Compare real estate activity across Omani governorates.
- Explore property prices and transaction values where data is available.
- Identify market patterns and potential investment opportunities.
- Build an interactive Power BI dashboard.

## Tools and Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Excel
- Power BI
- GitHub
- OpenAI Codex

## Data Sources
Official Omani government datasets and other reliable sources will be evaluated and documented. Only verified data will be used.
